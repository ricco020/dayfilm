# dayfilm

Join the first two seconds of every clip in a folder into one portrait film of the day, with ffmpeg.

    ./dayfilm.sh ~/Videos/today film.mp4

Page and explanation: https://ricco020.github.io/dayfilm/

The group version of this idea (friends film two seconds each, one shared film in the evening) is the app [Klapday](https://klapday.com/). MIT licence.
